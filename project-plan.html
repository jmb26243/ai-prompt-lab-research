Project Plan

Defining the vision, features, technical architecture, and development goals for AI Prompt Lab.

Three guiding ideas that define what we hope to create, what the first version must deliver, and what we want to learn.

✦

The vision

Create an interactive workspace where students can experiment with AI prompts, compare responses, and learn how different prompting approaches affect results.

Long-term vision
✓

USER REQUIREMENTS

Five core user stories

These stories describe what users should be able to accomplish when using the application.

01
ACCOUNT ACCESS

Create an account and sign in

As a student, I want to create an account and sign in so that my experiments remain private and accessible to me.

02
CORE INTERACTION

Create a prompt experiment

As a user, I want to record a prompt and its AI-generated response so that I can evaluate the outcome.

03
DATA PERSISTENCE

Save and revisit experiments

As a user, I want my experiments to be saved so that I can revisit them later, even after leaving the application.

04
PRIVATE DASHBOARD

Review experiment history

As a user, I want a private dashboard showing my previous experiments and ratings so that I can review my progress.

05
ACCOUNT MAINTENANCE

Manage my account

As a user, I want to update my display name and password so that I can maintain my account information.

SECURITY & PRIVACY

Protecting user accounts and data

Since the application stores personal accounts and private experiment records, security must be part of the design from the beginning.

🔒

Password protection

Passwords will be stored as secure hashes, not plain text. Password changes will require verification of the current password.

👤

Private user records

Every experiment will be associated with its owner. Server-side checks will prevent users from accessing another person's records.

✓

Protected account actions

Account updates and experiment operations will require authentication and appropriate authorization checks.

🧪

Security testing

Automated tests will check login behavior, protected pages, password changes, and separation of user data.

PROJECT BOUNDARIES

Defining the project scope

Keeping the first version focused will make development more manageable and allow us to prioritize the required account journey.

INCLUDED IN FIRST VERSION

Core functionality

  • User registration, login, and logout
  • Create and save prompt experiments
  • Record AI responses manually
  • Rate experiments and add notes
  • Private dashboard and experiment history
  • Update display name and password
DEFERRED FOR LATER

Possible future features

  • Direct integration with external AI APIs
  • Automatic prompt comparison
  • Sharing experiments with other users
  • Advanced charts and analytics
  • Community features and public profiles
  • Exporting experiment collections
Important: The initial version will allow users to paste AI responses manually. This avoids requiring an external AI API or paid service to complete the core workflow.
